# ADR 0002：分离无线承载层与 RadishLink 覆盖层

- 状态：Accepted
- 日期：2026-08-19

## 背景

802.11s 能形成链路级多跳网络，但不能直接提供离线消息的存储转发、端到端确认、用户身份、附件配额和跨承载切换。当前 MM8108/OpenWrt 的 Mesh 实现还存在实验性与区域限制。若把产品协议写死在某一驱动或 Mesh 模式上，法规、芯片或固件变化会迫使上层重写。

## 决策

在无线承载之上建立 RadishLink 覆盖层：

- 承载层只暴露邻接、MTU、链路指标和包/流传输能力；
- 覆盖层提供稳定节点身份、消息寻址、去重、TTL、存储转发、端到端确认和媒体准入；
- 端到端加密在覆盖层之上完成，中继不持有内容密钥；
- 同一协议必须可以在 HaLow、2.4 GHz 局域网和 Ethernet 模拟环境运行。

## 结果

- 可以在购买或合法发射 HaLow 设备前开发核心协议；
- 可以对比 802.11s、普通 AP/STA 与其他路由方案；
- 会增加一层协议和元数据，需要严格控制包头与重复状态；
- 不允许用覆盖层再实现无界全网洪泛，路由和存储必须有配额。
