# ADR 0005：Node 安全接入、撤销与证据寿命

- 状态：Accepted
- 日期：2026-10-24
- 接受者：项目所有者（本次会话明确接受 D6—D10）

## 背景

[ADR 0004](0004-node-service-foundation.md) 已确定 Node 单写者与 SQLite 联合事务。固定 mls-rs 源码核对表明，现成 SQLite provider 自行提交，不能加入 Node 的应用事务；中继清理证明、分区撤销与跨 boot 恢复也需要明确产品取舍。完整接入边界见[安全接入设计](../security/node-security-integration.md)。

## 决策

### D6：正式 storage traits 与 Node 唯一提交权

采用候选库公开 storage traits，由 Node 实现持久层，在一个连接与一个事务中提交 group/epoch、KeyPackage 消费及相关消息、历史、去重和证据责任。禁止 provider 自行提交、双库补偿或提前产生外部效果。失败后丢弃已经推进的内存会话；提交结果不确定时隔离并恢复核对。

新产品依赖图不引入旧 SQLite provider，单独审查实际闭包和 native 依赖；不修改历史 D2 图、provider、feature、源码或 lock 来追认旧结果。这接受接入路线，不代表 mls-rs 已通过功能、许可证或安全门。

### D7：两端 MLS 与独立可验证的送达证明

首期私聊按两个通信端点组成 MLS 会话，中继不持有内容密钥。活动前可信配对绑定参与者身份、MLS 凭据和独立证明验证公钥；中继按本地绑定验证目标端的送达证明。

采用标准签名对象方向，优先评审 COSE_Sign1 的成熟实现；证明绑定协议/证明类型、活动与重放范围、message key、不可变核心和密文摘要、目标凭据及其代数。不公开正文摘要，不信任 proof 自带公钥或仅凭 kid。精确算法、库、线格式、长度与身份绑定机制仍待验证和冻结。

目标端先在 T-C 持久提交安全状态、受保护记录、去重及可重建证明意图和返回责任，提交后才能签署和入队；中继 T-D 必须先共同提交有效证明的返回责任与清理结果。证明不等于已读，也不证明恶意目标端陈述真实。接受中继可观察活动内目标标识、消息关联与送达事实的隐私代价。

### D8：分层撤销与分区中的生效范围

手机界面撤销与通信身份撤销独立。界面撤销提交后拒绝新请求、阻止尚未交付的旧授权响应并关闭连接；不能收回已经显示的内容，不停止 Node 自身通信。通信身份撤销后，本机停止相应新业务、旧会话使用和证明接受。

首期保留离线能力，撤销在本机确认或收到并验证有权主体的撤销后生效，不承诺分区中的即时全队撤销。设备所有者的本地封禁为最终裁决；队友报告不自动获得全队撤销权，丢失设备由其他持有者分别确认封禁，替换身份重新配对。恢复联系时先处理有效撤销，再处理业务。

疑似泄露密钥撤销后新收到的旧键证明，不能凭自报时间接受；已提交历史送达事实保留。身份代数、MLS epoch 与本机授权修订分别管理，不能互相冒充或把不同节点的本机计数当作全局顺序。

### D9：首期冷启动隔离，暂缓透明续传

冷启动解锁后继续隔离旧会话及未完成传输责任，不重置寿命、不自动续传。重新通信需明确的新活动、新会话与可信重新配对流程；其实际机制和状态切换仍待验证，不提供忽略检查继续的入口。

LUKS 解锁、数据库计数器和正常关机标记不证明状态未回滚，普通墙钟不证明停机时长。透明续传必须同时证明可信剩余寿命和状态新鲜性，另行评审硬件或外部可信依据及成本。同 boot 的可信平台时钟与崩溃恢复不等于跨 boot 能力。

历史保留仍按 D5：时间不确定时不猜测到期、不提前删除；原有只读记录不能成为恢复旧授权、会话或发送责任的依据。

### D10：证明不超过原消息截止时间

证明生成和外发均受原消息的保守 deadline 约束，到点禁止；retain_until 只承担去重等保留责任，不能延长证明发送窗口。重复输入不重置返回队列或重试预算。迟到证明不复活已到期传输。

目标端已经持久交付的事实不因证明到期而消失；发送端若未及时获得证明，最终仍可能显示未获确认或到期，不能反推目标端未收到。去重 marker 和历史按各自窗口保留。

这是对 Node 产品行为及 SW-G3 修订中证据寿命规则的有限接受，不接受整份修订、数值 profile 或新的正式实验；旧 harness、spike 与历史结果保持原状。

## 实施授权与验证边界

所有者要求先固化文档和 ADR，再继续不受现行停止线阻塞的开发与验证。本批可使用已有工具链和依赖，实施 Node 内部证明意图、返回责任、截止时间、显式迁移和离线故障验证；测试只使用合成数据。

实际密码 storage trait 接入、COSE 签验、可信配对/撤销、平台时钟、防回滚和新活动恢复尚未完成。许可证/R2、Phase B、SW-G2、I5、HW/RF 等既有前置继续生效；本授权不包含依赖安装、系统配置、设备/VM 启动、网络实验、签名操作、采购或远程写入，也不包含 Git 提交。

接受设计不替代专业安全/许可证意见、实际候选故障验证或实体平台实测。遇到上述边界不能实现时报告并重评，不放宽保证以制造通过。
