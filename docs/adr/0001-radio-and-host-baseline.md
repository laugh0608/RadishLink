# ADR 0001：主机、长距无线与近距接入基线

- 状态：Accepted
- 日期：2026-08-19

## 背景

RadishLink 同时需要长距 Mesh、端到端加密、持久队列、实时 Opus、视频编解码、本机 UI 和手机接入。ESP32-S3 具备良好的 2.4 GHz/BLE、外设和 OTA 能力，但没有 HaLow 射频、Linux 多媒体生态或适合目标视频能力的硬件资源。MM8108 提供 HaLow 链路，但不是替代完整应用处理器的通用多媒体主机。

## 决策

1. 以嵌入式 Linux 应用处理器作为正式主系统基线。
2. 以 Wi-Fi HaLow 作为首个长距无线候选，以 MM8108 平台作为首轮评估对象。
3. 使用独立 2.4 GHz Wi-Fi / BLE 提供手机接入、配网和无线维护。
4. ESP32-S3 仅作为可选辅助 MCU，负责低功耗控制、按键、电源或看门狗；不作为首期中继主控。
5. POC 采用开发板和评估模块；量产 SoC、模块、天线与地区 SKU 等待法规和外场证据后冻结。

## 结果

- 软件可以获得成熟的 IP、多媒体、加密和存储能力；
- 手机接入不会要求手机支持 802.11ah；
- 原型功耗和体积不能代表产品，需要在 E0 重新选型；
- 双无线增加成本、天线布局和共存复杂度；
- HaLow 法规或成熟度失败时，可以替换长距承载而不推翻应用层。

## 未决定

- Linux 发行版与应用 SoC；
- ESP32-S3 是否进入最终 BOM；
- MM8108 是否进入量产；
- 具体视频编码、显示、摄像头和电池。
