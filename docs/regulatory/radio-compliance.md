# RadishLink 无线电合规前置条件

## 结论

Wi-Fi HaLow 是技术候选，不是一个可在所有国家使用相同频率、带宽、功率和天线的“全球免许可频段”。本项目在每个目标地区分别确认法规；芯片能够调到某个频率不代表可以合法发射。

本文不是法律意见。任何采购、进口、外场测试、认证或销售决定都需要供应商的地区材料和具备资质的本地专业方确认。

## 当前与中国大陆相关的已知事实

- Morse Micro `MM8108-MF15457` 数据表给出的可编程射频范围是 850–950 MHz。
- Morse Micro 的 HaLowLink 2 产品资料列出的支持地区为美国、加拿大、澳大利亚、英国、欧洲和日本，没有列出中国大陆。
- 工信部 2019 年第 52 号公告要求微功率短距离设备符合目录中的具体频率、功率、天线和使用场景，并禁止擅自扩频、加功率或更换天线。
- 工信部公开的 920–925 MHz RFID 技术要求采用不大于 250 kHz 占用带宽和跳频等专用条件，不能据此推导 1–8 MHz 的 802.11ah 可直接按 RFID 条件免许可使用。

因此，在获得明确书面结论前，RadishLink 不把 MM8108/HaLow 视为可在中国大陆公开外场发射的既定方案，也不购买未说明国内合规路径的设备用于随意试射。

## 地区预检表

每个测试地区建立一份记录，至少包含：

| 项目 | 需要的证据 |
| --- | --- |
| 国家/地区与具体地点 | 城市、室内/室外、是否处于机场或特殊电磁保护区域 |
| 设备身份 | 厂商、完整料号、硬件 revision、认证标识 |
| 监管域 | 固件设置、不可绕过机制、对应文档版本 |
| 频率与信道 | 中心频率、信道号、1/2/4/8 MHz 带宽 |
| 发射限制 | EIRP/ERP、占空比、驻留时间、功率谱密度 |
| 天线 | 型号、增益、极化、线损、是否允许更换 |
| 使用场景 | 室内/室外、固定/移动、个人实验/销售/进口 |
| Mesh 支持 | 当前固件是否在该监管域开放 802.11s/其他 Mesh |
| 责任结论 | 供应商、本地认证实验室或主管机构的书面答复与日期 |

## 测试门

### RF-R0：无发射开发

允许：文档、协议实现、网络模拟、加密与媒体本地环回。无需依赖 HaLow 设备。

### RF-R1：受控实验室

在专业方确认后，使用屏蔽箱、传导连接和衰减器进行不向外辐射的驱动与吞吐测试。具体实验仍需遵守设备进口、持有与实验室规则。

### RF-R2：近距离合法发射

地区、SKU、监管域、信道、功率和天线均有记录；先在短距离验证不会自动漂移到未允许配置。

### RF-R3：外场距离测试

除 `RF-R2` 条件外，还需选择允许地点、避开受保护区域、制定停止与干扰处理方案，并记录测试时间、位置和设备。

### RF-R4：工程样机/销售

重新评估整机天线、PCB、外壳、共存、电磁兼容、SAR/人体暴露、型号核准/认证、标签和说明书。评估模块的认证通常不能无条件覆盖自定义整机。

## 禁止事项

- 选择错误国家代码以获得更高功率或更多信道；
- 修改 BCF/监管数据库、驱动或固件绕过限制；
- 添加 PA、替换高增益天线或省略线损重新计算；
- 看到 920–925 MHz 即假设所有调制和 1–8 MHz 带宽都可用；
- 用“只测试几分钟”“个人项目”替代法规确认；
- 将国外外场数据写成国内产品能力。
