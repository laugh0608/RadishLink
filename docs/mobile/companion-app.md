# RadishLink 手机接入方案

## 定位

手机应用是附近 RadishLink Node 的伴侣终端。它利用手机更好的屏幕、键盘、摄像头、麦克风和耳机，但不取代随身设备的长距无线与中继能力。

## 首选连接方式

每台 Node 提供独立的 2.4 GHz 本地接入网络或受控局域网服务。用户扫描设备屏幕/标签上的一次性二维码完成：

1. 识别并验证设备身份；
2. 获取临时 Wi-Fi 接入或本地发现信息；
3. 建立应用层加密会话；
4. 将手机授权为本机界面、独立通信端点或临时媒体外设。

Wi-Fi 密码只提供局域网访问，不能替代设备身份验证。配对完成后，即使同一 Wi-Fi 上存在其他客户端，也不能访问消息。

## 手机可以承担的角色

- **遥控界面**：消息历史和密钥仍以 Node 为主，手机只显示与输入；
- **独立端点**：手机持有自己的端到端身份，Node 只转发手机产生的密文；
- **媒体端点**：手机完成拍摄、编解码和播放，Node 提供 HaLow 路由；
- **升级载体**：手机携带已签名固件包到无网设备，设备自行验签安装。

现有优先候选是“独立端点 + Node 路由”；它与下文 P0 本地 Web 的身份、历史和密钥归属尚未形成统一接受决定。不能直接假定浏览器、原生手机和 Node 是同一个端点；阶段收敛候选见下节。

## 身份与阶段收敛候选（待 SW-G2 评审）

2026-09-05 建议：P0 优先由 Node 持有通信身份、会话和受保护历史，本地 Web 作为该 Node 的已授权界面；原生手机独立身份在后续阶段单独进入多设备评审。该候选尚未冻结端点架构，不授权实现或将 Node 私钥导出到浏览器。

| 模式 | 内容与身份边界 | 手机缺席时的行为 |
| --- | --- | --- |
| Node 身份 + 本地界面候选 | Node 是 E2EE 端点；获授权的界面可以显示明文，界面终端属于需保护的明文边界；浏览器不保存长期身份私钥 | Node 用自身已建立身份继续收发，网页断开不退出会话 |
| 手机独立端点候选 | 手机持有独立身份与消息密钥；Node 对该会话只转发密文 | Node 不能解密手机消息或冒用手机身份；只能以自身获授权身份参与其他或已明确建立的多设备会话 |
| 同一用户多个端点 | 每个设备的身份、成员资格、历史同步与撤销关系需要显式协议 | 不承诺历史自动互通；需接受多设备方案后才能定义会话延续 |

SW-G2 接受前需写清：联系人显示的是用户还是设备、消息发给哪些端点、Node 与手机是否各为群组成员、历史同步权限、手机遗失/重装、Node 重置及分区期间撤销未知状态。UI 应区分未配对、身份已验证、身份变化、界面连接断开和消息已送达，不能把 Wi-Fi 连接成功当成身份验证。

本地 Web 的首次信任流程还须固定 HTTPS 证书/名称校验、二维码与设备身份绑定、会话建立与撤销、同网其他客户端拒绝策略。不得以长期忽略证书错误、共享万能凭据或把长期密钥写入浏览器存储作为默认方案。手机锁屏、网页刷新、离线网络切换和设备锁定列入用户路径验证；本轮没有宣称浏览器或原生流程已跑通。

## 手机为什么不能默认成为长距中继

- 主流手机没有 802.11ah/HaLow 射频，安装软件不会产生缺失的硬件能力；
- Android Wi-Fi Aware 从 API 26 提供邻近发现与直连，但并非所有设备支持，且与 SoftAP、Wi-Fi Direct 等并发能力依赖机型；
- iOS 26 在 iPhone 12 及以后机型引入 Wi-Fi Aware，但系统版本、机型和后台执行仍构成边界；
- Apple Multipeer Connectivity 在应用进入后台时会停止广播/浏览并断开会话，不适合作为无人值守中继承诺；
- 手机厂商的省电、热点和后台策略不可由 RadishLink 完全控制。

因此，手机到手机的 Wi-Fi Aware/平台 P2P 只作为近距机会式扩展实验。基础产品保证是“手机连接最近的 RadishLink Node”，长距中继仍由 Node 完成。

## POC 到产品的客户端路线

### P0：本地 Web

- Node 提供仅本地可达的 HTTPS/WebSocket 界面；
- Mac、Android 和 iPhone 无需安装即可完成文字、状态与基本设置；
- 浏览器不承担后台中继、长期密钥保管或最终实时媒体承诺。

### P1：原生伴侣应用

- 采用共享业务核心和 Android/iOS 原生网络适配层；
- 评估 Flutter 作为 UI，与本地核心通过清晰 FFI/API 边界协作；
- 处理系统权限、本地网络授权、前后台切换、音频会话和二维码扫描；
- 所有敏感身份使用系统安全存储，并提供设备撤销入口。

### P2：机会式手机直连

- 在运行时检测 Wi-Fi Aware/平台 P2P 能力；
- 只在用户明确启用、应用处于允许状态和电量策略满足时转发；
- 不影响不支持该能力的手机使用 Node；
- 单独测量后台存活、并发 Wi-Fi、耗电和跨平台互通。

## 设备独立操作最低集

没有手机时，Node 至少提供：

- 已验证联系人和群组选择；
- 预设短语与短文字输入；
- 未读通知与消息阅读；
- 按住说话或接听/挂断实时语音；
- 电量、链路等级、当前中继策略和隐私状态；
- 锁定、关机、紧急清除本机会话入口。

摄像头与完整视频 UI 可以晚于文字/语音，但不能把“有手机”写成设备核心功能的隐含前提。
