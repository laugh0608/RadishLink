## 先回答“现在是否要买设备”

**现在不采购。** 2026-10-09 所有者已确认没有可复用设备，当前按三节点及必要配件全新增核算，先完成[低成本硬件验证计划](hardware-validation-plan.md)的候选/BSP 与 BOM 评审；不继续等待复用清单，也不假定能借到设备。`HW-G2` 未通过前不下单；HaLow 采购继续暂停，并受独立射频合规门约束。

当前实体化顺序是：软件前置与采购门满足后，购买三台一致的低成本 Linux SBC 完成 `HW1` 纯有线台架；之后只增加一块 ESP32-S3 与最少外设完成 `HW2`。不要先买三块 MCU 或一块地区不明的 HaLow 模块。

## HaLow 采购前置门（后续）

向供应商、当地无线电管理专业人员或认证实验室书面确认：

- 实际测试国家/地区；
- 精确料号和硬件 revision；
- 固件监管域与允许信道；
- 1/2/4/8 MHz 中哪些带宽可用；
- 最大发射功率、天线增益、占空限制和室内/室外条件；
- 评估设备进口、持有和外场发射所需手续；
- 802.11s 在该监管域和当前固件是否可选。

未关闭这些问题前，只允许依法合规的无辐射/屏蔽/传导测试方案，并应由专业方确认实验安排。

## ESP32-S3 的采购边界

在 `HW1` 与 IPC 边界评审后，最多购买 1 块带 PSRAM、USB 和目标显示/音频接口的 ESP32-S3 开发板，用于验证：

- 按键、显示、电池计量和低功耗唤醒；
- 首次 USB 刷写后的局域网签名 OTA；
- 主处理器关机/唤醒与看门狗协议。

在 Linux 三节点 POC 完成前，不买三套 ESP32-S3，也不投入它与 MM8108 的自定义 PCB。MCU 无线默认关闭，不能用其 2.4 GHz 结果替代 HaLow 或产品近距接入结论。

## 这一阶段不要买

- 只支持 LoRa/FSK 的模块作为实时语音视频主链路；
- 地区版本不明、不能锁定监管域的 HaLow 模块；
- 外接功率放大器、高增益改装天线或“解锁全频段”设备；
- 只凭峰值 PHY 速率宣传、没有 Linux/OpenWrt 驱动与参考设计的模块；
- 最终屏幕、摄像头、电池和外壳的大批量物料；
- 两台节点后就宣称完成 Mesh 的采购方案。

## 到货验收

1. 拍照记录料号、revision、天线、序列号和包装地区标记；
2. 保存供应商页面、数据表、固件与校验值，不依赖未来可能变化的下载链接；
3. 在不发射或合法的台架条件下验证启动、恢复、Ethernet/USB 和日志；
4. 三台升级到同一已记录固件，禁用自动漂移；
5. 备份原始配置和恢复镜像；
6. 完成近距离单跳、三节点中继和断电恢复后，才进入距离阶梯测试。
